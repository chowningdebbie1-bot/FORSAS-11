# Forsas

Welcome to **Forsas**! 🖥️

Forsas is a custom web-based computer interface made with **HTML, CSS, and JavaScript**. It is designed to feel like a complete computer system, with its own startup experience, lock screen, desktop, windows, and menus.

## ✨ Features

* 🚀 Animated Forsas startup screen
* 🔒 Lock screen
* 🖥️ Desktop interface
* 📂 Start menu
* 🪟 Window system
* ⏰ Clock and date display
* 🌤️ Weather display
* 💻 Interactive interface
* 🎨 Custom Forsas design
* 🌐 Runs directly in a web browser

## ▶️ Running Forsas

You can run Forsas by opening the main HTML file in a modern web browser.

If this project is hosted with **GitHub Pages**, you can also access it directly from its website.

## 🛠️ Built With

* HTML
* CSS
* JavaScript
